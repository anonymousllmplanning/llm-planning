# WWW 2027 source release

`framework_source.zip` contains the experimental framework and synthetic tests.
`SOURCE_MANIFEST.json` records the source file sizes and SHA-256 hashes.
`SHA256SUMS` covers the source files, validation metadata, and archive.

This release contains no experimental result tables, model trajectories,
historical checkpoints, paper source files, or gated benchmark records.
See the repository README for installation and required local inputs.

`VALIDATION.json` summarizes executed offline checks and their limits.
